# macOS Collector

Run `collect-android-logs.command` from Finder, or execute `./capture-android-logs.sh` in Terminal. Configure ADB in
`adb.config`; an empty value uses the current shell `PATH`. If ADB is missing, the script asks before using Homebrew.

See the [macOS guide](../../docs/en/macos.md) or [macOS 使用说明](../../docs/zh-CN/macos.md) for the complete workflow.
