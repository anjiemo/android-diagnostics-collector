# Android 日志采集工具使用说明

## Windows

1. 在 `platforms/windows/adb.config` 中配置 `ADB_PATH`，留空时读取 Windows `PATH`。
2. 双击 `platforms/windows/开始采集Android日志.bat`。
3. 连接并授权 Android 设备，按提示选择设备和目标 App 包名。
4. 选择是否录屏；直接按回车或输入 `N` 表示不录屏，输入 `Y` 表示启用。
5. 操作 App 复现问题，回到窗口按回车确认现场。
6. 等待现场快照、录屏导出和 bugreport 完成。

详细说明见 [中文项目 README](README.md)。英文平台说明见 [Windows Guide](../en/windows.md)。

## macOS

1. 在 `platforms/macos/adb.config` 中配置 `ADB_PATH`，留空时读取当前 shell 的 `PATH`。
2. 首次使用执行 `chmod +x platforms/macos/capture-android-logs.sh platforms/macos/collect-android-logs.command`。
3. 双击 `platforms/macos/collect-android-logs.command`，或在终端执行：

   ```bash
   ./platforms/macos/capture-android-logs.sh
   ```

4. 找不到 ADB 时，工具会询问是否使用 Homebrew 安装 Android platform-tools。
5. 按提示选择设备、输入包名和是否录屏，完成复现后按回车。
6. 等待现场信息、录屏和 bugreport 导出完成。

详细说明见 [中文项目 README](README.md)。英文平台说明见 [macOS Guide](../en/macos.md)。

## 录屏限制

Android 原生 `screenrecord` 通常最长 180 秒且不含设备音频。录屏失败不会中断 Logcat、现场快照或 bugreport 采集，
结果会写入 `采集摘要.txt`。

## 输出位置

```text
results/windows/AndroidLogs_yyyyMMdd_HHmmss_SERIAL/
results/macos/AndroidLogs_yyyyMMdd_HHmmss_SERIAL/
```
